🔬 國中化學黑板教室：氧化還原的競爭法則與電子轉移

兩種黑色粉末，怎麼變出紅色的銅？從搶氧大戰到電子轉移，看懂氧化還原的本質。

曉臻老師的疑問
古人是怎麼從黑黑的礦石裡煉出亮晶晶的銅？把黑色的氧化銅和黑色的碳粉混在一起加熱——兩種黑色粉末，竟然會變出紅色的銅！
秘密是一場搶氧大戰：活性比較大的碳，把氧化銅的氧搶走了。照課本的步驟組裝裝置，親眼看看。

    曉臻老師的實驗提示

    🔬 微觀競爭法則

    這是一場為了爭奪「氧原子」而發生的化學競爭：

    • 現象觀察： 試管內黑色的混合粉末，加熱後表面逐漸析出紅棕色的斑點（銅）；同時產生的氣體導入澄清石灰水中，使其變為混濁乳白色。
    • 競爭原理： 因為碳的活性大於銅（C > Cu），在高溫狀態下，碳強行奪取了氧化銅中的氧。
    • 產物分析： 紅棕色固體點狀物為銅 (Cu)；使石灰水變混濁的氣體為二氧化碳 (CO2)。
    2 CuO + C → 2 Cu + CO2
    曉臻老師說
    這一頁是補充內容（高中會用到）：搶氧的一方叫還原劑，被搶的一方叫氧化劑。讀完定義，到最下面的實驗台挑戰你的直覺：二氧化碳明明是拿來滅火的，點燃的鎂帶伸進去，竟然還能繼續燃燒！

    🏷️ 概念定義 (補充內容)

    在化學反應中，物質扮演的角色可以根據其「目的」來命名，這在高中化學非常關鍵：

    還原劑 (Reducing Agent)

    本身發生氧化反應（得到氧）。因為它把氧搶走，促使另一種物質「被還原」，所以它是幫助別人還原的媒介。

    氧化劑 (Oxidizing Agent)

    本身發生還原反應（失去氧）。因為它提供氧給別人，促使另一種物質「被氧化」，所以它是幫助別人氧化的媒介。

    ⚔️ 實戰判定心法

    以剛才的實驗 2 CuO + C → 2 Cu + CO2 為例：

    • 碳 (C)： 活性大，負責搶氧（被氧化），所以碳是強效的還原劑。
    • 氧化銅 (CuO)： 活性小，被迫失去氧（被還原），所以氧化銅是氧化劑。

    活性大的金屬（或碳）通常是良好的「還原劑」。
    它們極易與氧結合，常被工業上用來冶煉金屬礦物。

      曉臻老師的挑戰
      把鋅片泡進藍色的硫酸銅溶液，這個反應裡沒有誰得到氧、也沒有誰失去氧，鋅片表面卻長出紅棕色的銅，藍色也慢慢褪掉——不靠搶氧，也能氧化還原？關鍵在看不見的電子。放大到原子的世界看看。

      ⚡ 打破氧的迷思 (高中先修)

      許多化學反應「沒有氧氣參與」，卻仍然具有氧化還原的特徵。科學家發現，氧化還原的本質其實是電子的轉移：

      • 氧化反應： 物質失去電子的過程。
      • 還原反應： 物質得到電子的過程。

      由於電子帶負電，失去電子會讓物質的相對正電荷（氧化數）升高，得到電子則會讓正電荷降低。

      🔬 實驗台：金屬放進硫酸銅溶液

      左邊是燒杯裡真正看得到的變化，右邊的圓圈放大到原子：看電子從哪裡跑到哪裡。

      金屬

      ✂️ 半反應式拆解

      以金屬鈉與氯氣反應生成氯化鈉為例：
      2 Na + Cl2 → 2 NaCl

      這個過程並沒有氧，我們將其拆解為微觀的電子轉移：

      氧化半反應 (失去電子)：

      Na → Na+ + e-

      鈉原子失去電子，被氧化，作為還原劑。

      還原半反應 (得到電子)：

      Cl2 + 2 e- → 2 Cl-

      氯分子得到電子，被還原，作為氧化劑。

      曉臻老師的挑戰
      搶氧、活性大小、電子轉移——前面三個分頁的本事都學會了嗎？
      四道資優題，一關一關破。先自己想，卡住了再看提示。

      巨觀判定

      鎂帶在二氧化碳中能夠持續燃燒，反應式為：
      2 Mg + CO2 → 2 MgO + C
      請問在這個反應中，誰被氧化？誰是氧化劑？

      提示

      請觀察反應前後，哪一個物質「得到氧原子」？哪一個物質「失去氧原子」？

      解答

      鎂 (Mg) 得到氧，被氧化。
      二氧化碳 (CO2) 失去氧被還原，負責提供氧，因此是氧化劑。

      活性邏輯推演

      已知化學反應 X + YO → XO + Y 可自然發生，但反應 Z + XO → 無反應。
      請問 X, Y, Z 三種金屬的活性大小排序為何？

      提示

      反應能發生，代表單獨的元素「成功搶走了氧」。誰搶贏了，誰的活性就比較大。

      解答

      1. X + YO → XO + Y 發生了，代表 X 成功搶走 Y 的氧，故活性 X > Y。
      2. Z + XO → 無反應，代表 Z 搶不走 X 的氧，故活性 X > Z。
      結論：X 的活性最大。 (但無法比較 Y 和 Z)

      電子轉移判定

      觀察以下離子反應方程式：
      Zn + Cu2+ → Zn2+ + Cu
      請問哪一個物質「失去電子」被氧化？哪一個是還原劑？

      提示

      電子帶負電。從原本不帶電 (0) 變成帶正電 (+2)，代表身上的負電變多了還是變少了？

      解答

      Zn 變成 Zn2+，代表它失去了 2 個電子，被氧化。
      因為它被氧化，所以它擔任的是還原劑的角色。

      跨單元實驗陷阱

      將鐵片放入藍色的硫酸銅水溶液中，鐵片表面會析出紅色的銅，反應式：Fe + CuSO4 → FeSO4 + Cu。
      這個過程中，誰發生了還原反應？水溶液的顏色會如何變化？

      提示

      溶液呈現藍色是因為含有銅離子 (Cu2+)。當銅離子變成銅原子析出時，藍色會變深還是變淺？

      解答

      硫酸銅中的銅離子 (Cu2+) 得到電子變成銅原子，發生還原反應。
      隨著藍色的銅離子減少，並產生淺綠色的亞鐵離子，水溶液的顏色會由藍色逐漸變淡（或呈微綠色）。
