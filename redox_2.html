氧化還原的競爭法則與電子轉移

巨觀實驗觀察

將氧化銅與碳粉均勻混合後裝入試管，準備加熱。

微觀競爭法則

這是一場為了爭奪「氧原子」而發生的化學競爭：

  • 現象觀察： 試管內黑色的混合粉末，加熱後表面逐漸析出紅棕色的斑點（銅）；同時產生的氣體導入澄清石灰水中，使其變為混濁乳白色。
  • 競爭原理： 因為碳的活性大於銅（C > Cu），在高溫狀態下，碳強行奪取了氧化銅中的氧。
  • 產物分析： 紅棕色固體點狀物為銅 (Cu)；使石灰水變混濁的氣體為二氧化碳 (CO2)。
2 CuO + C → 2 Cu + CO2

概念定義 (補充內容)

在化學反應中，物質扮演的角色可以根據其「目的」來命名，這在高中化學非常關鍵：

還原劑 (Reducing Agent)

本身發生氧化反應（得到氧）。因為它把氧搶走，促使另一種物質「被還原」，所以它是幫助別人還原的媒介。

氧化劑 (Oxidizing Agent)

本身發生還原反應（失去氧）。因為它提供氧氣給別人，促使另一種物質「被氧化」，所以它是幫助別人氧化的媒介。

實戰判定心法

以剛才的實驗 2 CuO + C → 2 Cu + CO2 為例：

  • 碳 (C)： 活性大，負責搶氧（被氧化），所以碳是強效的還原劑。
  • 氧化銅 (CuO)： 活性小，被迫失去氧（被還原），所以氧化銅是氧化劑。

活性大的金屬（或碳）通常是良好的「還原劑」。
它們極易與氧結合，常被工業上用來冶煉金屬礦物。

打破氧的迷思 (高中先修)

許多化學反應「沒有氧氣參與」，卻仍然具有氧化還原的特徵。科學家發現，氧化還原的本質其實是電子的轉移：

  • 氧化反應： 物質失去電子的過程。
  • 還原反應： 物質得到電子的過程。

由於電子帶負電，失去電子會讓物質的正電荷（氧化數）升高，得到電子則會讓正電荷降低。

半反應式拆解

以金屬鈉與氯氣反應生成氯化鈉為例：
2 Na + Cl2 → 2 NaCl

這個過程並沒有氧，我們將其拆解為微觀的電子轉移：

氧化半反應 (失去電子)：

Na → Na+ + e-

鈉原子失去電子，被氧化，作為還原劑。

還原半反應 (得到電子)：

Cl2 + 2 e- → 2 Cl-

氯分子得到電子，被還原，作為氧化劑。

挑戰一：巨觀判定

鎂帶在二氧化碳中能夠持續燃燒，反應式為：
2 Mg + CO2 → 2 MgO + C
請問在這個反應中，誰被氧化？誰是氧化劑？

鎂 (Mg) 得到氧，被氧化。
二氧化碳 (CO2) 失去氧被還原，負責提供氧，因此是氧化劑。
挑戰二：活性邏輯推演

已知化學反應 X + YO → XO + Y 可自然發生，但反應 Z + XO → 無反應。
請問 X, Y, Z 三種金屬的活性大小排序為何？

1. X + YO → XO + Y 發生了，代表 X 成功搶走 Y 的氧，故活性 X > Y。
2. Z + XO → 無反應，代表 Z 搶不走 X 的氧，故活性 X > Z。
結論：X 的活性最大。
挑戰三：電子轉移判定

觀察以下離子反應方程式：
Zn + Cu2+ → Zn2+ + Cu
請問哪一個物質「失去電子」被氧化？哪一個是還原劑？

Zn 變成 Zn2+，代表它失去了 2 個電子，被氧化。
因為它被氧化，所以它擔任的是還原劑的角色。
挑戰四：跨單元實驗陷阱

將鐵片放入藍色的硫酸銅水溶液中，靜置一段時間後，鐵片表面會析出紅色的銅，反應式為：Fe + CuSO4 → FeSO4 + Cu。
這個過程中，誰發生了還原反應？水溶液的顏色會如何變化？

硫酸銅中的銅離子 (Cu2+) 得到電子變成銅原子，發生還原反應。
隨著藍色的銅離子減少，並產生淺綠色的亞鐵離子，水溶液的顏色會由藍色逐漸變淡（或呈微綠色）。
