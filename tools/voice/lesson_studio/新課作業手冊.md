# 做新一課「有聲講解」：作業手冊（2026-11-11，electronics_2 驗證成功）

**老師只需要對 Claude 說一句：「做 <課名> 的有聲講解」**（例如：做 electronics_3 的有聲講解）。
Claude 讀完 `AGENTS_VOICE.md` 和這份就知道怎麼做，不用老師貼流程、不用老師操作錄音。

## 老師要做的（只有兩件事）
1. 審稿：Claude 寫完對話稿後，看內容、用字、每句長短。
2. 聽 + 看：Claude 推上分支後，在網頁上聽一遍，回報「第幾句」切畫面不對或唸錯。
   推上 main（學生看得到）之前，要老師說 OK。

## Claude 的步驟（全部在雲端做）
1. **寫稿**：只讀 `lessons_md/<課>.md`（不要讀整份 html）。彥君老師 × 曉臻助教，約 100～130 句；含 `＊切頁`、`＊停`、`＊釘選`；合聲獨立成句。
   不放英文字母與阿拉伯數字；N 極寫「恩極」、S 極寫「艾斯極」。存到 `tools/voice/lesson_studio/scripts/<課>_script.txt`。
2. **設定檔**：`tools/voice/lesson_studio/lessons/<課>.json`（cuts／steps／at／acts／expect_lines／expect_chorus）。範例：`electronics_2.json`（最完整）。
3. **切畫面（派 Opus）**：用 Agent 工具、`model: opus`，請它逐句對照頁面的分頁／子頁／步驟按鈕，
   **講到串聯、並聯、電流、電子、電池顆數等，畫面上對應的按鈕就要真的被點到**；句子中途要換時用 `acts`。
   要求它改完自己跑逐句模擬（`tools/voice/lesson_studio/sim/sim_lines_electronics_2.js`，新課要改裡面的 `want()`、`CVS`、選擇器）並回報結果。
   Opus 要先讀頁面自己的「老師講解模式」STAGE 表與 setter 函式；不改動畫、物理、題目邏輯（只加外層屬性）。
   頁面若已有示範介面（例如 `window.WIRING`），直接呼叫，不另做動畫。
4. **建置**：`python3 tools/voice/lesson_studio/build_lesson.py --lesson <課>`（驗證通過才會寫 `audio/<課>/manifest.json`、`stage.json`、`stage_spec.md`）。
5. **錄音**：`python3 tools/voice/lesson_studio/cloud_tts.py <課>`
   - 出現 `No audio was received` 就**重跑**（只補缺的檔，有時要跑 2～4 次）。
   - 結果檢查：manifest 每個 `file` 都存在、大於 1000 bytes、沒有多餘檔。
6. **播放器**：（含「自動螢光筆」：唸到公式的句子，要在播放器加 `HL` 表讓公式跟著語音畫黃線，規則與範例見 `AGENTS_VOICE.md` 第 8-1 節；範本 `work_2_voice_v1.js`）
   複製 `electronics_2_voice_v1.js` 當範本（`<課>_voice_v1.js`），改 SCENES 對應該課的按鈕；html 加 `<script defer src="<課>_voice_v1.js?v=日期-版本">`；改播放器就換版本號。
7. **獨立驗證**：git 乾淨、build 通過、音檔齊全、整課模擬重跑：`mismatches: 0`、`js errors: none`、`mode-teacher 出現次數：0`。
   本機：repo 根目錄 `python3 -m http.server 8803`，再 `NODE_PATH=$(npm root -g) node tools/voice/lesson_studio/sim/sim_lines_electronics_2.js`（約 4 分鐘）。
8. **推分支 `<課>-audio`** → 老師聽看 → 老師說 OK → 才推 main。commit 結尾加 Co-Authored-By 與 Claude-Session 兩行。
9. **完成後**：把這課學到的新東西補進本檔「踩過的雷」。

## 讀音（錄音用的字典 `class_studio.py` 的 `PRON`，全課共用）
- 「差」一律讀一聲（叉）→ 字典 差→插。
- 動詞「量」（量電流、量電壓、量兩點、要量的、量到）讀二聲 → 字典 量→良；名詞（力量、電量、能量、量程）不改。
- 動詞「數」（數數看）讀三聲 → 字典 數數看→鼠鼠看（2026-11-19，plant_structure 第 73 句）；「倒數」則是倒三聲、數四聲。
- 「剝」（剝皮、剝掉、環剝）唸 bō → 字典 剝→播（2026-11-19，plant_structure 第 84、95、96、109 句）。
- 「轉」一律讀三聲（zhuǎn）→ 字典 轉→膞（2026-11-20，astronomy_earth_motion_2 含「轉」的 41 句已重錄；新單元遇到「轉」會自動套用，請聽一下確認）。
- 艾斯→誒死。腳本裡有別的破音字或難唸字，先補字典再錄；字幕不受影響。
- 不確定時，旁白改寫成沒有歧義的字（例如動詞「量」改「測」）。

## 螢光筆（2026-11-12 起，每課都要做）
- 每一句唸到公式／算式的話，畫面上的公式要用黃色螢光筆跟著畫（字幕照跑）。做法與驗證見 `AGENTS_VOICE.md` 第 8-1 節。

## 改稿、改句子時
- 稿子中間增減句子 → 後面所有句號順延：`at`、`acts` 的鍵、`expect_lines`、`expect_chorus` 都要同步改（用腳本一次平移，不要手改）。
- 只重錄有變的句子：用（說話者, 文字）比對舊新 manifest，沒變的舊 mp3 改名成新檔名，其餘刪掉後重跑 `cloud_tts.py`。
- 只改讀音：字典加字 → 刪該句 mp3 → 重跑 `cloud_tts.py`。
- 只改字幕：改 stage 的 `subs`，不用重錄。

## 踩過的雷
- 頁面自己的老師模式導覽（`body.mode-teacher`）會和語音搶著切分頁 → 播放器用 MutationObserver 播放時強制回學生模式。
- 換分頁／子頁才捲到畫布；用 `prev` 比對「換之前」，不要先覆蓋再比較。
- 畫布比螢幕高（接線練習）→ 播放時用 `fitWire()` 縮到字幕框上方，停止時還原。
- 偵測「目前子頁」要在 `.tab-content.active` 範圍內找，否則被隱藏的分頁會讓模擬誤報。
- 改完播放器，請老師「硬重新整理」（Ctrl+Shift+R）再看，否則看到舊的。
- 本機 `python3 -m http.server` 不支援 Range（測快轉會誤判）；逐句模擬用假音訊，所以沒問題。
- 雲端 edge-tts 偶爾對某一句固定回「No audio was received」（plant_structure 第 97 句）：換個措辭重建再錄；錄音慢時用 `SHARD=i/n`（例 `SHARD=1/6`）開多個程序平行錄。
- 頁面有開場封面（`#introScreen`）時，模擬／測試要先點封面，否則按鈕被擋住點不到。
- 螢光筆的 `e`（結束字）不要放在句尾，放前面一點，否則在模擬裡會被判「到下一句才畫滿」。
- GitHub Release 不要放音檔（iPad 不能播）；音檔放 `audio/<課>/mp3/`。

## 這課新學到的雷（astronomy_earth_motion_2）
- 舊頁的 `.tab-btn` 沒有 `data-tab` 時，`build_lesson.py` 的驗證會找不到分頁：在按鈕上加 `data-tab="tab1"`～`tab5`（外層加法、不影響原功能），設定檔就能用 tab1～tab5。
- 稿子第一句之前沒有 `＊切頁` 時，第 1 句要在 `at` 設一個畫面（例如 tab1 第 1 步），否則逐句模擬的期望狀態是空的。
- 雲端新工作階段要先 `pip install --break-system-packages edge-tts certifi` 才能錄音；錄一次約 5 分鐘，會被 timeout 切掉，重跑只補缺的檔（本課跑了 3 輪才全數成功）。
- 頁面缺封面檔時（`assets/covers/<課>_cover_v1.jpg` 404），頁面會把封面直接移除；做有聲講解前先確認封面載入正常。

- astronomy_moon_phases_4（月相、日月食與潮汐，93 句，2026-11-20，分支 `astronomy_moon_phases_4-audio`）：頁面沒有 data-tab，`lessons/*.json` 用 `tab_check: [html, "id"]`、分頁名稱寫 `btn-tab-0～3`、步驟編號自訂（月相分頁 4～7＝朔／上弦／望／下弦）；播放器直接按頁面老師講解用的按鈕（`clk`），並凍結／還原 `S.play*`。
- **釘選黃條的位置**：`＊釘選` 會顯示在「它後面那些句子」，直到下一個釘選或切頁。要把它放在講那件事的句子**前面**，不要放在句子後面；否則換步驟後還掛著上一步的黃條。
- 字幕數字：`subtitle_digits.py` 現在會轉「小時、天、圈、句尾的分」（十二小時二十五分→12 小時 25 分）。

- earth_strata_3（岩層密碼與地球歷史，113 句，2026-11-20，分支 `earth_strata_3-audio`，待老師聽）：五個分頁各一個實驗台（fd／ft／ev／pe／fs＋cr），播放器照頁面老師講解的做法直接呼叫頁面原本的 `labGo`、`peGo`、`crPick`，並複製老師模式的 `labJump` 做「快轉／跳句時把前面的步驟瞬間跑完」；沒做螢光筆（沒有可畫的 DOM 公式）。

## 這課新學到的雷（earth_strata_3）
- 實驗台引擎（`labGo`）做完一步，下一步若是「先猜猜看」，頁面會**自動**出現猜題選項；所以 `at` 設在「前一步」時，動畫一播完畫面就變成猜題（引擎本來的行為，不是切錯）。逐句模擬要把這種情況算對（`GUESS_AFTER`）。
- 步驟編號不可為 0（`build_lesson.py` 要求 1 起算）：分頁剛切進來的初始狀態沿用「＊切頁」（播放器 step 0＝初始，`cuts` 不給步驟）；需要在分頁中途回到初始，就多留一個步驟編號給「初始」（例：古環境分頁 1＝初始）。
- 某一步動畫比該句語音還長時，下一個切點會用 `labJump` 瞬間跑完而截斷動畫：切點要放在動畫能播完之後（本課把「先猜」的切點從第 91 句挪到第 92 句）。
- 播放器的暫停：實驗台用 `performance.now()` 算進度，暫停要每 30 毫秒把正在播的那一段 `cur.t0` 往後推（同頁面老師講解）。
- `subtitle_digits.py` 新增保護詞「幾百／幾千／幾萬」（不要把「幾百公里」轉成「幾 100 公里」）。
- earth_taiwan_quake_4（臺灣與地震，131 句，2026-11-20，分支 `earth_taiwan_quake_4-audio`，待老師聽）：頁面是「實驗台引擎」（LABS：tw／qm／fc／mg／wn，全域 labGo／labGuess／labReset／SC／scPick），沒有 data-tab；設定檔用 `tab_check`＋`btn-tab-0～4`，步驟編號＝播放器 `ACTS` 表的第 n 個動作（fresh／go／show／pick／scv／sc／end），`_note` 有對照。
- **實驗台切畫面的做法**：不點按鈕，直接 `labGo(id)`（動畫現場播）；沒播完就 `whenReady` 等（最多 12 秒）否則 `jumpTo`（複製頁面老師模式的 labJump，把前面的步驟瞬間跑完，猜猜看步驟順便選好正確答案）；暫停＝每 16 ms 把 `L.cur.t0` 往後推；停止＝每個實驗台 jumpTo 回開始前那一步。`LABS`、`SC` 是頁面全域 const，播放器與模擬都可以直接讀。
- **逐句模擬的期望值**要用「實驗台狀態」比：`L.i` 與是否在跑（go k：k 或 k+1；show k：k；pick k：k+1）；`show` 和上一個 `go` 跑完後的狀態相同，無法區分，兩者都容許。

## 這課新學到的雷（earth_taiwan_quake_4）
- 播放器複製月相課的範本後，刪掉「動畫狀態」那一段時，**`var pauseSaved = null;` 也在裡面**，漏補會讓 `start()` 丟 `pauseSaved is not defined`，整課模擬 16 分鐘後才發現一句都沒觀察到。複製範本後先用 `SMOKE=45` 跑 45 秒再跑整課。
