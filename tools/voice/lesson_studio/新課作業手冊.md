# 做新一課「有聲講解」：作業手冊（2026-11-11，electronics_2 驗證成功）

**老師只需要對 Claude 說一句：「做 <課名> 的有聲講解」**（例如：做 electronics_3 的有聲講解）。
Claude 讀完 `AGENTS_VOICE.md` 和這份就知道怎麼做，不用老師貼流程、不用老師操作錄音。

## 老師要做的（只有兩件事）
1. 審稿：Claude 寫完對話稿後，看內容、用字、每句長短。
2. 聽 + 看：Claude 推上分支後，在網頁上聽一遍，回報「第幾句」切畫面不對或唸錯。
   推上 main（學生看得到）之前，要老師說 OK。

## Claude 的步驟（全部在雲端做）
1. **寫稿**：只讀 `lessons_md/<課>.md`（不要讀整份 html）。彥君老師 × 曉臻助教，約 100～130 句；含 `＊切頁`、`＊停`、`＊釘選`；合聲獨立成句。
   不放英文字母與阿拉伯數字；N 極寫「恩極」、S 極寫「艾斯極」。存到 `tools/voice/lesson_studio/scripts/<課>_script.txt`。
2. **設定檔**：`tools/voice/lesson_studio/lessons/<課>.json`（cuts／steps／at／acts／expect_lines／expect_chorus）。範例：`electronics_2.json`（最完整）。
3. **切畫面（派 Opus）**：用 Agent 工具、`model: opus`，請它逐句對照頁面的分頁／子頁／步驟按鈕，
   **講到串聯、並聯、電流、電子、電池顆數等，畫面上對應的按鈕就要真的被點到**；句子中途要換時用 `acts`。
   要求它改完自己跑逐句模擬（`tools/voice/lesson_studio/sim/sim_lines_electronics_2.js`，新課要改裡面的 `want()`、`CVS`、選擇器）並回報結果。
   Opus 要先讀頁面自己的「老師講解模式」STAGE 表與 setter 函式；不改動畫、物理、題目邏輯（只加外層屬性）。
   頁面若已有示範介面（例如 `window.WIRING`），直接呼叫，不另做動畫。
4. **建置**：`python3 tools/voice/lesson_studio/build_lesson.py --lesson <課>`（驗證通過才會寫 `audio/<課>/manifest.json`、`stage.json`、`stage_spec.md`）。
5. **錄音**：`python3 tools/voice/lesson_studio/cloud_tts.py <課>`
   - 出現 `No audio was received` 就**重跑**（只補缺的檔，有時要跑 2～4 次）。
   - 結果檢查：manifest 每個 `file` 都存在、大於 1000 bytes、沒有多餘檔。
6. **播放器**：複製 `electronics_2_voice_v1.js` 當範本（`<課>_voice_v1.js`），改 SCENES 對應該課的按鈕；html 加 `<script defer src="<課>_voice_v1.js?v=日期-版本">`；改播放器就換版本號。
7. **獨立驗證**：git 乾淨、build 通過、音檔齊全、整課模擬重跑：`mismatches: 0`、`js errors: none`、`mode-teacher 出現次數：0`。
   本機：repo 根目錄 `python3 -m http.server 8803`，再 `NODE_PATH=$(npm root -g) node tools/voice/lesson_studio/sim/sim_lines_electronics_2.js`（約 4 分鐘）。
8. **推分支 `<課>-audio`** → 老師聽看 → 老師說 OK → 才推 main。commit 結尾加 Co-Authored-By 與 Claude-Session 兩行。
9. **完成後**：把這課學到的新東西補進本檔「踩過的雷」。

## 讀音（錄音用的字典 `class_studio.py` 的 `PRON`，全課共用）
- 「差」一律讀一聲（叉）→ 字典 差→插。
- 動詞「量」（量電流、量電壓、量兩點、要量的、量到）讀二聲 → 字典 量→良；名詞（力量、電量、能量、量程）不改。
- 艾斯→誒死。腳本裡有別的破音字或難唸字，先補字典再錄；字幕不受影響。
- 不確定時，旁白改寫成沒有歧義的字（例如動詞「量」改「測」）。

## 改稿、改句子時
- 稿子中間增減句子 → 後面所有句號順延：`at`、`acts` 的鍵、`expect_lines`、`expect_chorus` 都要同步改（用腳本一次平移，不要手改）。
- 只重錄有變的句子：用（說話者, 文字）比對舊新 manifest，沒變的舊 mp3 改名成新檔名，其餘刪掉後重跑 `cloud_tts.py`。
- 只改讀音：字典加字 → 刪該句 mp3 → 重跑 `cloud_tts.py`。
- 只改字幕：改 stage 的 `subs`，不用重錄。

## 踩過的雷
- 頁面自己的老師模式導覽（`body.mode-teacher`）會和語音搶著切分頁 → 播放器用 MutationObserver 播放時強制回學生模式。
- 換分頁／子頁才捲到畫布；用 `prev` 比對「換之前」，不要先覆蓋再比較。
- 畫布比螢幕高（接線練習）→ 播放時用 `fitWire()` 縮到字幕框上方，停止時還原。
- 偵測「目前子頁」要在 `.tab-content.active` 範圍內找，否則被隱藏的分頁會讓模擬誤報。
- 改完播放器，請老師「硬重新整理」（Ctrl+Shift+R）再看，否則看到舊的。
- 本機 `python3 -m http.server` 不支援 Range（測快轉會誤判）；逐句模擬用假音訊，所以沒問題。
- GitHub Release 不要放音檔（iPad 不能播）；音檔放 `audio/<課>/mp3/`。
