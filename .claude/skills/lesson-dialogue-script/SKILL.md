# 課程對話稿（彥君老師 × 曉臻助教）

用在：要替 Physical-Boys 的某一課產出「老師講解」模式的錄音稿。學生自己看的講解文字不要改。

## 先省 token
- 不要讀整份課程 html（約 9 萬字元）。只取該課的講解文字、分頁標題與子頁名稱；使用者貼給你，或用抽取程式產生的摘要。
- 需要確認細節時，再用 grep 查特定段落，不整檔讀。
- 一課一個新對話，不在長對話裡接著寫。

## 角色
- 彥君老師：理化老師，開場、主講、收尾。男聲（zh-TW-YunJheNeural）。
- 曉臻助教：充滿好奇，負責提問、補充、替學生說出疑惑。女聲（zh-TW-HsiaoChenNeural）。
- 流程：彥君開場說今天要上哪一課 → 曉臻好奇提問（要被回答）→ 進入教學內容 → 彥君收尾。
- 兩人像上課一樣自然對話，不是念講義。

## 稿子格式（可直接貼進「彥君和曉臻錄音工作室」）
- 每行一句，約 20～40 字，行首寫說話者：`彥君： …`、`曉臻： …`、`合聲： …`（兩人一起念）。編號不用寫。
- 標記行（不錄音）：`＊切頁：<分頁問題標題>`、`＊停：<秒>`、`＊釘選：<重點短句>`。
- 10 分鐘約 2,500～3,000 字。

## 讀音稿規則（稿子裡寫的就是要念的字）
- 不放英文字母、不放阿拉伯數字，數字寫中文。
- 字母讀法：N 極寫「恩極」；S 極寫「艾斯極」（錄音工作室的讀音字典會把「艾斯」轉成 a死，這是使用者試聽確認最標準的念法）。
- **class_studio.py 的 PRON 不會套用到 TTS**（TTS 念的是稿上的字）。要改讀音：稿中直接寫同音字（例：參宿四寫「身秀四」），再把字幕對照加進 `build_lesson.py` 的 `SUB_MAP`（例：`("身秀四","參宿四")`），然後刪掉該句 mp3 重錄。

## 字幕稿
- 畫面上顯示的字和念的字可以不同（例如字幕寫 N 極、念恩極）。對照寫在該課的 stage.json 的 `subs`，key 是句子編號（如 "08"）。
- stage.json 另有：`page`（課程 html 檔名）、`cuts`（＊切頁文字 → {tab, sub}）、`at`（句子編號 → {tab, sub}，到那句時切分頁）。tab、sub 對應課程頁 `.tab-button[data-tab]` 與 `.sub-tab-btn[data-sub]`。

## 切畫面原則（有聲講解播放器）
- 重點是動畫不是文字：動畫步驟以 `.v5-cv` 畫布為主，整張畫布必須在字幕框上方的主屏內；狀態說明字放得下才一起顯示。不要用整個 stage 或 `anchor:'bottom'`。
- 畫螢光線若要去到畫面外，畫完馬上拉回動畫主畫面。

## 輸出方式
- 回覆只給：① 一個程式碼區塊的稿子 ② 一個程式碼區塊的 stage.json 草稿。不重述過程。
- 檔案位置：錄音在桌面「課程錄音／<課名>／」，stage.json 放同一資料夾；試聽用桌面「課程試聽播放器」。

## 待定（不要自行補）
- 8字臻言收尾：內容與由誰念尚未決定。
- 彥君、曉臻的表情／姿勢切換尚未設計。
