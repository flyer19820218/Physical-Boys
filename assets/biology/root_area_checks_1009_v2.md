# 生物 4-2：根毛吸收表面與移植供需比較

日期：2026-10-09。只修改老師指定的根毛分頁；本機提交，未推送。

## 教學修正

- 完整根毛：三根根毛的上側、下側、尖端附近，以及健康表皮表面都有短距離跨膜移動。位置取自實際繪製的輪廓，不再讓分子沿兩條長路線排隊鑽入。
- 根毛受損：淡虛線標記已失去的接觸表面；水不進入虛線區，剩餘健康表皮仍可吸水。比較有效吸收表面的損失，不模擬傷口漏水或癒合。
- 一般外液與過濃外液都保留；濃液時跨膜淨移動反向。不是「面積越大就一定吸水」。
- 移植：同一種泛用幼苗的三情境並排，分別是完整根毛、受損根毛但葉量不變、相同受損根搭配較少葉片。兩個相鄰比較各只改一项；可點圖或控制列看原因。
- 移植比較固定一般土壤溶液。幼苗是原創供需模型，不冒充特定植物或實拍；根毛與水分子已放大。
- 圖內線段長短、分子數及移動速度都是定性辨識，不是面積比、百分比或測得的吸水速率。
- 減少葉面積用來解釋蒸散需求降低，不寫成所有移植植物都要截枝。說明保留葉片對根部恢復的養分供應，以及保護根團、合宜供水等適用界線。
- 康軒根毛原始照片未改動，照片來源紀錄保留；只是顯示於放大模型旁的觀察證據欄。
