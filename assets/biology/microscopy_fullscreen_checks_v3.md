# 顯微鏡 V3 全螢幕：驗證紀錄

2026-10-06：老師已確認 V3 並授權上架；發布版僅更換「本機樣版」標籤，保留 V3 的模型與全螢幕介面。

## 改動範圍

- 保留 1080px 一般教材框架。只有老師明確要求的全螢幕操作模式鋪滿視窗。
- 四個操作區加入全螢幕：器材辨認、倍率／光源／對焦、倒像、移動生物追蹤。
- 橫式：左側 340px 控制欄獨立捲動，右側顯微視野；直式：視野在上，控制在下。
- 每個操作區都有由原始 width/height 推得的 `--ar`，Canvas 為 1，照片為 455/600。
- Canvas 寬度同時受右欄可用寬、右欄可用高 × `--ar` 限制；不更動內部 640×640 尺寸。
- 正常退出、Escape、瀏覽器自行退出、全螢幕請求被拒、延遲完成、切頁時均處理。
- 同一批操作節點移入側欄，沒有複製 controls、id 或 Canvas。真正全螢幕內保留中文／英文切換。
- 器材介紹改用 Mark192 的實體顯微鏡照片；作者、來源、CC BY-SA 2.5 在圖片下方。原圖位元組保留未改。
- 未刪任何檔案，V2 預覽及原 SVG 留存。

## 科學模型保護

`assets/biology/microscope.js` 與 V2 預覽內的原腳本逐字一致；所有原數值座標、倍率、倒像、游動軌跡及速率未變。全螢幕使用獨立的 CSS 與 UI 腳本。

## 測試結果

模型測試（Node + 原生 Canvas raster）：倍率 40／100／400×、相對視野直徑 100／40／10%、高倍鎖粗調、反方向移動、三種標本與數字、游動、雙語後繼續游動、暫停與切頁清除 RAF 均通過。游動約一秒差 979 像素；英文後仍差 849 像素，與 V2 相同。

新增 UI 邏輯測試（非瀏覽器）：四個操作區重排、同一 controls 引用、語言切換、Escape、拒絕原生全螢幕時的固定視窗備援、原生退出事件、延遲進入後清理、切頁退出、只有三張原 Canvas 均通過。

尺寸算式核對：iPad Pro 13／12.9／11、Air、10.2、mini 與手機橫式尺寸中，畫布寬不超過右欄，畫布高不超過可用高。這是算式核對，**不是瀏覽器排版或按鈕中心命中檢查**。

## 驗證限制

本機 HTML 的瀏覽器自動預覽曾被工具安全限制阻擋，未嘗試替代入口繞過。因此實際 Safari／iPad 顯示、Google Fonts 是否載入、雙語長字換行、按鈕觸控中心點與原生全螢幕仍待老師開啟 V3 檢查。不能宣稱已完成實機 fscheck。
