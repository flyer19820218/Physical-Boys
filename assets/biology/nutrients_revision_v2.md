# 3-1 V2｜玻片上的處理後樣本液

2026-10-07。老師明確要求在玻片上顯示液體，不顯示整塊原型食物。

- 原版直到預測並準備後才畫小液滴，選單狀態因而看起來空白。
- 修正版選樣時就顯示「樣本液預覽 · 未加碘液」。甲為選定的處理後樣本，乙為透明清水；兩邊等大液滴。
- 澱粉液、米飯研磨液為乳白／略混濁，香蕉研磨液淡米黃色；葡萄糖、蔗糖和清水透明。這些是定性的外觀示意，不表示樣本濃度或提前揭曉檢驗結果。
- 液滴增加立體弧面、接觸陰影、反光與可見邊缘；米飯／香蕉只有很細微的懸浮顆粒，顆粒裁在液滴內，不放完整飯粒或香蕉。
- 液滴中心和滴管落點仍在原玻片中心，沒有改玻片／桌面／瓶子／滴管幾何、滴液軌跡、檢驗答案、計量或時間。
- 保留先預測，再確認樣本、加液、比較的步驟。碘液的原「放上各一滴樣本」改為「確認各一滴樣本」，如實區分預覽與檢驗確認。未確認不能加碘液，初始不顯示藍黑／黃褐反應色。
- 新預覽 `biology_nutrients_sample_drops_preview_1007_v2.html` 引用新 `nutrients_draw_v2.js`／`nutrients_v2.js`；V1 HTML 和 JS 完整保留。共用 V1 模型與 CSS，沒有改動其他單元或首頁。
- `nutrients_check_v2.cjs` 包含初始可見、六種選樣、液滴邊界、雙語、V1 本氏液逐像素不變、原 12 個檢驗案例、操作先後、動畫一秒差、觸控、暫停及狀態保留等檢查。
