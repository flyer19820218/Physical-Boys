# 細胞 V4｜真實照片 × 顯微鏡操作

範圍：只加強最後「標本觀察」分頁，前面三頁的教學、照片、剖面與製片流程不重做。

## 老師確認與授權

- 三段總倍率 **40／100／400 倍**。目鏡固定 10 倍，物鏡為 4／10／40 倍，三者清楚分開標示。
- 最後一頁不展示卡通細胞模型，只用真實細胞照片；舊 V1 科學原始碼逐字保留，舊 UI 隱藏且不啟動胞質流動。
- 「顯微鏡操作」和「原始照片」是兩個不同模式：前者移動玻片造成影像反向，後者拖曳照片只是數位瀏覽。

## 光學示意界線

- 操作模式用同一張實拍模擬倍率、取樣視野、光線與失焦，**不是三個倍率各自重新拍攝**，不增加新的細胞細節；所有來源及原拍攝倍率照舊列出。
- 相對視野直徑依倍率反比，40／100／400 倍分別為 100%／40%／10%。
- 滿照明時的低倍畫面和高倍畫面不是靠換顏色區分。固定初始照明下的透光係數：4× 物鏡 1、10× 0.62、40× 0.28；學生必須自行補光，切換倍率不自動調燈。
- 燈／光圈滑桿的響應為定性教學映射，不是照度測量。高倍粗調鎖定，只能細調；轉高倍保留玻片位置，不自動置中。
- iPad 觸控玻片、拖曳視野均代表移動玻片；玻片右移→影像左移、上移→影像下移。未放玻片時不接受移片。
- 原始照片模式保持單指拖曳、雙指縮放，不加方向鍵。
- 失焦優先用 Canvas filter；不支持 filter 的 Canvas 使用 5×5 加權平移疊圖近似模糊，鏡框與目鏡十字不跟著失焦。
- 黃色玻片點只為定位參考，不是細胞核或葉綠體。

## 操作流程

裝薄玻片 → 低倍找標本 → 低倍粗調再細調 → 置中 → 換高倍 → 補光 → 高倍細調。
「確認這一步」只在條件達成時推進，不替學生調焦、移片或補光；可以自由試誤再回到步驟。

「裝上玻片／確認這一步」置於操作欄最上方；調焦與載物臺採可展開區塊，依當前流程展開，避免 iPad 操作欄一次塞滿所有控制。
