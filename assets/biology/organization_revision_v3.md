## 實作

- 新預覽 `biology_organization_visual_flow_preview_1007_v3.html`，獨立 V3 JS、CSS、圖集資料。正式頁、V1、V2與其他協作者檔案不覆寫。
- 人體：細胞 → 組織 → 器官 → 器官系統 → 個體；整個人包含頭、手與腳。消化系統以完整身體輪廓定位，不把軀幹截圖冒稱完整個體。
- 植物：依講義第11頁四層整理，細胞 → 組織 → 器官 → 個體。不是宣称進階植物學沒有根系／地上系。完整番茄根、莖、葉、花、果實示意。原植物六器官真圖與葉組織解說保留為可展開補充。
- 概覽只有圖像、層次名稱與箭頭；沒有十一張文字卡。點圖選中後該欄加寬，圖下再顯示較大的同圖與簡短形狀／功能解說；看全部層次／收起解說可回到概覽。
- 第三頁依明確授權皮膜改同圖集的示意，標示非實拍；血液、肌肉、單細胞、神經、保衛細胞原照片、觀察語句與授權保留。植物六器官真圖仍支援觸控移動與縮放。
- 全螢幕人體五欄、植物四欄按原順序占滿橫向空間，不套照片觀察室340px左欄。照片觀察室仍保留原左右控制格；主要按鍵至少48px。
- 圖集原PNG不改像素，inline SVG viewBox顯示各插圖。AI非實拍、不同層次不同比例、原創生成提示詞與素材路徑另記。
