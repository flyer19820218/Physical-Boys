## 舊模型保護

與 V1 檢查版逐字比對：plantCell、swimBody、makeStage、move、stopTracking、startTracking 六函式相同；scale、imagePoint、organism、stageFactor 四個倍率／座標／游速入口相同。新增不同標本與字形選項，不宣稱整份繪圖演算法沒有變。

## 尚未驗證的項目

測試是 Node 模型＋原生 Canvas raster，不是瀏覽器整頁驗證。瀏覽器安全限制使本機 HTML 預覽無法由工具載入；未繞過限制。因此 iPad／手機實際排版、Google Fonts 真正載入、getComputedStyle 與手指拖曳仍須老師開啟新預覽確認，不能視為已通過。

## 靜態與動態

器材圖、軟木／綠藻／矽藻圖、選鏡說明是靜態。倍率／亮度／焦距與倒像按操作重畫；只有游動追蹤需要持續動畫。封面使用 CSS 緩慢推鏡，尊重 reduced-motion。
