# 手部姿勢庫：來源與授權紀錄（2026-11-28）

- 性質：**本站原創的 3D 建模渲染**（不是照片、不是課本圖像、不是 AI 影像生成）。手部造型由程式（`tools/hands/build_hand_v2.py`）用距離場（SDF）數學式建出，再以 Blender 5.3（bpy、Cycles、Freestyle）渲染成透明底 PNG。
- 沒有使用第三方模型、貼圖或照片。開發過程中曾評估 WebXR `generic-hand`（MIT）與 Handy.js（MIT）、LibHand、MakeHuman，**最後都沒有採用**，成品不含它們的任何資料。
- 製作：Claude（Opus 建模與渲染、Sonnet 整理），由老師（Soulrunning）指定需求與風格；老師 2026-11-28 指示：以後手部動作用這套設計（見 `AGENTS.md` 3.2）。
