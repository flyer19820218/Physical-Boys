# 正式首頁：圖片選單與 iPad 三欄 · 2026-10-08

## 授權與範圍

依老師「看不到圖片式選單、iPad 請改成三欄」的要求，正式更新首頁。此前 `index_static_covers_preview_1008_v1.html` 僅是本機預覽，未发布。舊正式首頁使用 `repeat(auto-fit,minmax(320px,1fr))`；iPad 可用寬度不足三張卡片時會自動變成兩欄，不能歸因於快取。

本版只新增首頁圖片卡片、專用樣式、縮圖與紀錄。所有教材 HTML、繪圖／動畫／實驗、原圖、原影片、首頁既有語言與学科切換 JS 均不改寫。原有 Claude／老師的修改與刪除保留，不納入本次提交。

## 版面

- 主框架仍為 1080px；電腦與全寬 iPad 均使用三欄 `repeat(3,minmax(0,1fr))`，不再有平板兩欄斷點。
- 寬度不超過 599px 使用單欄；手機及極窄分割視窗依此保護。欄數依 CSS 視窗寬度決定，不偵測裝置名稱。
- 卡片上方完整等比圖片，下方原有標題與說明，不壓字到封面上。標題統一 22px，次要說明 17px；各裝置不偷偷縮字，文字自然換行。
- 圖片使用專用 960px 以內的縮圖，影片首幀則保持抽圖原樣。83 張縮圖總計約 9.3 MB，延後載入，不載入或播放影片／音訊。
- 保留 98 個教材入口、24 個章節與生物優先順序。新縮圖與 CSS 使用新檔名，HTML 加入版本標記 `static-covers-ipad3-1008-v2`。
