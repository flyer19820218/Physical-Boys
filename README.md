# 黎明國中自然科學與數理互動教學總庫
(Science Interactive Curriculum Platform)

## 專案簡介
這是一個專為國中自然科學設計的 **HTML5 互動式教學網站**。  
本系統旨在透過高解析度動態圖解、Canvas 互動模擬器與邏輯清晰的排版，幫助學生建構直觀且紮實的科學概念。

## 視覺與排版核心規範
為了保障課堂大螢幕投影效果與學生的閱讀舒適度，全站嚴格遵守以下開發原則：

1. **零黑色護眼原則 (Dark Chalkboard Theme)**
   * 背景嚴格採用吸光深黛綠（`#11261f` / `#16332a`）。
   * 嚴禁任何純黑色字體與線條，文字一律採用高對比粉筆亮色（純白、亮橘 `#FFA500`、亮青 `#00FFFF`、草綠 `#7CFC00`、螢光桃紅 `#FF69B4`）。
2. **大螢幕滿版雙欄排版**
   * 採用 CSS Grid `grid-template-columns: repeat(auto-fit, minmax(420px, 1fr))`。
   * 專為 iPad 橫置與觸控屏幕最佳化，保證畫面工整不跑位。
3. **字體地板與防斷字綁定 (Typography & No-Wrap)**
   * 內文基礎字體堅持最低 20px。
   * 為了避免化學符號（如 `Cl` 與 `I`）混淆，數學變數與化學式統一綁定高辨識度的 **`Verdana`** 字體。
   * 專業術語、單位、公式嚴格加入 `white-space: nowrap;` 防斷字機制。
4. **標準理化上下分式**
   * 徹底摒棄單行斜線（`/`）的排版，物理公式與化學莫耳數計算一律使用 CSS `flex` 建構專業的垂直上下分數線。
