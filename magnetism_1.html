磁鐵與磁場

從看不見的磁力線到地球大磁鐵，解開空間中的磁力密碼。

為什麼叫 N 極與 S 極？

將一塊磁鐵用細線懸吊在空中，讓它自由旋轉，靜止後會發生神奇的現象：

  • 受地球磁場影響，磁鐵會恆指向南北方向。
  • 指向北方的紅色端，稱為 指北極 (N 極)。
  • 指向南方的藍色端，稱為 指南極 (S 極)。
動手玩：在右側的立體空間中，直接用滑鼠去「左右拖曳」磁鐵，看看它放開後如何擺盪回南北向！

同名相斥，異名相吸

磁鐵任何形狀都有兩個不同的磁性端，稱為磁極。

  • 當兩塊磁鐵靠近時，同名極互相排斥。
  • 異名極互相吸引。
不管磁鐵多大或多小，N 極與 S 極永遠成對出現！

磁極永遠成對出現

如果把一塊長條形磁鐵從中間折斷，會發生什麼事？

  • 斷裂處會自動產生新的磁極。
  • 切斷後的每一小塊，都會保有完整的 N 極與 S 極。
  • 無法單獨分離出只有 N 極或只有 S 極的「單極磁鐵」。

【互動】磁極實驗室

受地球磁場影響，懸吊磁鐵靜止後，紅色端必定指向北方。這就是指南針的原理。

問題

將一塊磁鐵等分成三段，總共會出現幾個 N 極與幾個 S 極？

提示

切斷磁鐵時，磁極會不會消失？每一段是不是都是獨立的磁鐵？

解答

總共會有 3 個 N 極與 3 個 S 極。因為每一段都會成為具備完整雙極的新磁鐵。

把鐵變成磁鐵

可以被磁鐵吸引、甚至被磁化的物質稱為磁性物質，例如：鐵、鈷、鎳及其合金。

將原本沒有磁性的鐵釘靠近磁鐵，使其暫時具有磁性的現象稱為磁化。

  • 硬磁性物質 (如鋼)：不容易被磁化，但磁化後磁性可長久保存。
  • 軟磁性物質 (如軟鐵)：容易被磁化，但磁鐵移開後磁性容易消失。
高溫加熱或劇烈撞擊，會破壞內部磁疇排列，使磁鐵失去磁性！

如何正確保存磁鐵？

為了避免磁性隨著時間流失，必須讓磁力線形成封閉的迴路：

  • 長條形磁鐵：應將兩支磁鐵的 N 極與 S 極反向並排，並在兩端吸附軟鐵片。
  • U 字形磁鐵：直接在兩極之間吸附一塊軟鐵片即可。

【動畫】微觀世界下的磁化

鐵塊內部有許多小磁區(磁疇)，平常排列凌亂，整體不具磁性。

問題

工廠要製造能長時間吸附在冰箱上的造型磁鐵，內部應該選擇軟鐵還是鋼？

提示

軟鐵的磁性容易消失，鋼的磁性可以長久保存。

解答

應該選擇鋼 (硬磁性物質)，才能確保製成永久磁鐵後磁性不易流失。

看見磁場的形狀

真實的磁場看不見，我們透過鐵粉或「假想的磁力線」來描繪：

  • 方向：外部必定由 N 極出發，回到 S 極。形成封閉曲線。
  • 強弱：磁力線越密集的地方，代表磁場越強。
  • 磁力線永遠不會相交！

特殊的均勻磁場

U 字形磁鐵（或馬蹄形磁鐵）的設計，可以將 N 極與 S 極拉近：

  • 在 U 字形的兩個磁極之間，磁力線幾乎是互相平行的直線。
  • 這代表兩極之間的空間擁有非常均勻的強磁場。

【互動】撒鐵粉實驗室

第一步：請點擊按鈕撒下散亂的鐵粉。

問題

長條形磁鐵的正中央地帶，磁力線分布非常稀疏，這代表什麼意義？

提示

磁力線的「疏密程度」代表了磁場的什麼特性？

解答

代表磁鐵中央地帶的磁場非常微弱（稱為中性區）。磁力主要集中在兩端磁極。

定義磁場的方向

空間中任何一點的磁場方向，是透過指南針來定義的：

  • 將指南針靜置於磁場中，N 極所指的方向即為該點的磁場方向。
  • 在圖形上，磁場方向剛好與該點磁力線的切線方向一致。
切線方向就是物體沿著曲線運動時，瞬間「飛出去」的直線方向。

解題必考：磁針偏轉

考試常將多個磁針放置於磁鐵周圍，請記住兩大原則：

  • 磁針的 N 極會被磁鐵的 S 極吸引。
  • 如果把磁力線畫出來，磁針的 N 極一定會順著箭頭的「切線方向」指過去。

【互動】隨動磁針與切線

👆 直接在畫布上拖曳磁針！ 觀察紅色 N 極如何精準順著切線方向轉動。

問題

若將小磁針放在磁鐵外部正中央的上方，磁針的 N 極會指向哪個方向？

提示

把小磁針拖曳到互動圖中磁鐵的「正上方」看看，磁力線是從 N 極出發走向 S 極。

解答

磁針的 N 極會指向平行於磁鐵並朝向 S 極的方向（切線方向）。

為什麼指南針能指北？

在地球表面，只要不受其他磁鐵干擾，指南針的 N 極永遠會指向北方。

  • 這代表地球本身就是一顆巨大的磁鐵，周圍充滿了地磁場。
  • 地磁場可以阻擋太陽風與宇宙射線的直擊，保護地球上的生命。

破除迷思：地理北 ≠ 地磁北

運用「異名極相吸」的原理來推理：

  • 能把指南針 N 極吸向北方的，必定是 S 極。
  • 因此，在地球的「地理北極」附近，其實隱藏著地磁南極 (S極)！
  • 相反地，「地理南極」附近則是地磁北極 (N極)。兩者夾角約有 11 度。

問題

既然地球是一顆大磁鐵，那麼地球外部的磁力線，是從南方流向北方，還是從北方流向南方？

提示

觀察透視圖中的紫色磁力線箭頭方向，磁力線永遠是從 N 極出發。

解答

從南方流向北方。因為「地磁 N 極」位於地理南極附近，磁力線由南半球出發，流向北半球的「地磁 S 極」。
