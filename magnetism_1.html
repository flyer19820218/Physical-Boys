磁鐵與磁場

從看不見的磁力線到地球大磁鐵，解開空間中的磁力密碼。

為什麼叫 N 極與 S 極？

將一塊磁鐵用細線懸吊在空中，讓它自由旋轉，靜止後會發生神奇的現象：

  • 受地球磁場影響，磁鐵會恆指向南北方向。
  • 指向北方的紅色端，稱為 指北極 (N 極)。
  • 指向南方的藍色端，稱為 指南極 (S 極)。
💡 觀察：動畫會自動播放，撥轉幾次，磁鐵最後都擺回南北向。想再看一次，按畫面下方的步驟編號！

同名相斥，異名相吸

磁鐵任何形狀都有兩個不同的磁性端，稱為磁極。

  • 當兩塊磁鐵靠近時，同名極互相排斥。
  • 異名極互相吸引。
不管磁鐵多大或多小，N 極與 S 極永遠成對出現！

磁極永遠成對出現

如果把一塊長條形磁鐵從中間折斷，會發生什麼事？

  • 斷裂處會自動產生新的磁極。
  • 切斷後的每一小塊，都會保有完整的 N 極與 S 極。
  • 無法單獨分離出只有 N 極或只有 S 極的「單極磁鐵」。

【互動】磁極實驗室

受地球磁場影響，懸吊磁鐵靜止後，紅色端必定指向北方。這就是指南針的原理。
曉臻老師說：
一根普通鐵釘本來吸不住別的釘子，為什麼用磁鐵摩擦幾下，它就能吸起迴紋針？答案藏在鐵裡面的小磁區（磁疇）。

把鐵變成磁鐵

可以被磁鐵吸引、甚至被磁化的物質稱為磁性物質，例如：鐵、鈷、鎳及其合金。

將原本沒有磁性的鐵釘靠近磁鐵，使其暫時具有磁性的現象稱為磁化。

  • 硬磁性物質 (如鋼)：不容易被磁化，但磁化後磁性可長久保存。
  • 軟磁性物質 (如軟鐵)：容易被磁化，但磁鐵移開後磁性容易消失。
高溫加熱或劇烈撞擊，會破壞內部磁疇排列，使磁鐵失去磁性！

如何正確保存磁鐵？

為了避免磁性隨著時間流失，必須讓磁力線形成封閉的迴路：

  • 長條形磁鐵：應將兩支磁鐵的 N 極與 S 極反向並排，並在兩端吸附軟鐵片。
  • U 字形磁鐵：直接在兩極之間吸附一塊軟鐵片即可。

看見磁場的形狀

真實的磁場看不見，我們透過鐵粉或「假想的磁力線」來描繪：

  • 方向：外部必定由 N 極出發，回到 S 極。形成封閉曲線。
  • 強弱：磁力線越密集的地方，代表磁場越強。
  • 磁力線永遠不會相交！

特殊的均勻磁場

U 字形磁鐵（或馬蹄形磁鐵）的設計，可以將 N 極與 S 極拉近：

  • 在 U 字形的兩個磁極之間，磁力線幾乎是互相平行的直線。
  • 這代表兩極之間的空間擁有非常均勻的強磁場。

定義磁場的方向

空間中任何一點的磁場方向，是透過指南針來定義的：

  • 將指南針靜置於磁場中，N 極所指的方向即為該點的磁場方向。
  • 在圖形上，磁場方向剛好與該點磁力線的切線方向一致。
切線方向就是物體沿著曲線運動時，瞬間「飛出去」的直線方向。

解題必考：磁針偏轉

考試常將多個磁針放置於磁鐵周圍，請記住兩大原則：

  • 磁針的 N 極會被磁鐵的 S 極吸引。
  • 如果把磁力線畫出來，磁針的 N 極一定會順著箭頭的「切線方向」指過去。

指南針的 N 極為什麼會指向地理北方？答案有點反直覺：地理北極附近，其實藏著一個地磁 S 極。

為什麼指南針能指北？

在地球表面，只要不受其他磁鐵干擾，指南針的 N 極永遠會指向北方。

  • 這代表地球本身就是一顆巨大的磁鐵，周圍充滿了地磁場。
  • 地磁場可以阻擋太陽風與宇宙射線的直擊，保護地球上的生命。

破除迷思：地理北 ≠ 地磁北

運用「異名極相吸」的原理來推理：

  • 能把指南針 N 極吸向北方的，必定是 S 極。
  • 因此，在地球的「地理北極」附近，其實隱藏著地磁南極 (S極)！
  • 相反地，「地理南極」附近則是地磁北極 (N極)。兩者夾角約有 11 度。
