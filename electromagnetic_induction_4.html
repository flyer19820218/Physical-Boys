電磁感應與交流電

從法拉第的一次發現，走進發電、變壓與感應加熱。

老師講解：按下去就從這個分頁的第一個場景開始，步驟一個接一個連續播到底，可暫停、重播，也可以點步驟編號跳到那一步。學生操作：一次只播一個步驟，播完就停住；想看下一步就按下一個編號。
曉臻老師說：
為什麼拿一塊磁鐵在線圈旁邊晃來晃去，就會突然跑出電來？難道磁鐵裡面藏著電池嗎？

不是有磁鐵就有電流

1831 年，法拉第展示了利用磁產生電流的裝置：線圈內的磁場發生改變，就會產生電流。

  • 磁鐵與線圈都不動：磁場不變，沒有感應電流。
  • 移動磁鐵或移動線圈都可以；關鍵是兩者有相對運動。
  • 相對移動越快：磁場改變越快，感應電流越大。
  • 線圈匝數越多：感應電壓越大，因此感應電流通常越大。
電磁感應：線圈內磁場發生改變而產生電流；這個電流稱為感應電流。

感應電流反抗「改變」

冷次定律：感應電流產生的磁場，會反抗原來磁場的改變。

  • N 極靠近：線圈近端變成 N 極，排斥靠近。
  • N 極遠離：線圈近端變成 S 極，吸引它回來。
它反抗的是「變化」，不是永遠排斥磁鐵。
阻力將動能換成電能。
資優補充：冷次定律超出一般國中範圍；圖中只用一條原磁場與一條反向感應磁場，先掌握方向即可。

【動畫】磁鐵靠近線圈

磁鐵靜止：磁通量沒有改變，電流為 0。

曉臻老師說：
發電機的線圈一直轉，為什麼有時候產生直流電，有時候卻是交流電？秘密到底藏在哪個零件裡？

外力旋轉：直流發電機

將動能轉換為電能。外力轉動線圈，配合分裂環即可輸出直流電。

  • 場磁鐵固定，提供穩定的磁場。
  • 電樞與分裂環一起旋轉，切割磁力線。
  • 分裂環每半圈交換接點，將輸出的波形翻轉成單一方向的直流脈衝！
動能 → 電能 (直流電)

同一部機器：改由外力轉動

交流發電機改由外力轉動電樞，使磁通量持續改變並感應出交流電。

  • 把分裂環改成兩個一前一後的完整雙滑環。
  • 線圈每轉半圈，輸出極性自然交換。
  • 固定電刷把交流電送到外電路。
動能 → 電能

【動畫】直流發電機構造

波形觀測重點

分裂環讓輸出的電流方向永遠保持一致（正向或負向）。

曉臻老師說：
手機充電器那麼小一個，是怎麼把牆壁裡危險的 110V 高壓電，變成安全的 5V 的？

用匝數比改變交流電壓

一次線圈接交流電，產生不斷改變的磁場；軟鐵芯容易被磁化，可增強並引導磁場進入二次線圈，再感應出交流電壓。

VsVp＝NsNp
  • 同一側線圈：圈數越多，感應電壓越大。
  • Ns ＞ Np：升壓，二次電壓較高。
  • Ns ＜ Np：降壓，二次電壓較低。
  • 直流電只在接通、切斷瞬間有磁場變化，無法持續變壓。
理想變壓器近似功率守恆：升壓時電流會變小；降壓時電流會變大。

【動畫】磁場傳遞與感應電壓

一次線圈接交流電，鐵芯裡的磁場來回改變；二次線圈因磁通量改變而感應出電壓。

為什麼感應效果看起來慢四分之一週期？

先講結論：不是電磁場傳得慢。動畫中的可見錯開，主要是磁通量與感應電壓之間的微分關係；它們相差 90°，不是訊號延遲了四分之一週期。

① 先估算真正的傳播時間

電磁擾動在介質中的速率由介電常數與導磁率決定；在真空中就是光速。變壓器不是單純的自由空間電磁波，但用光速做數量級估算，已足以看出傳播時間極短。

v＝1√(με) ； Δtprop＝Lv

若裝置尺度取 0.30 m，並用光速估算：

Δtprop＝0.30 m3.00 × 108 m s−1＝1.0 × 10−9 s
約 1 奈秒；課堂動畫完全看不出這麼短的時間。

② 磁通量：線圈真正感受到的量

線圈是否產生感應電壓，不只看磁場強弱，還要看穿過線圈面的磁場總量是否改變。這個量稱為磁通量。

ΦB＝∫A B · dA
ΦB＝BA cos θ
第二式適用於均勻磁場與平面線圈。
B磁場強度
A線圈面積
θ磁場與線圈面積法線的夾角

③ 法拉第定律：關鍵是變化率

N 匝線圈的感應電動勢，等於磁通量對時間變化率的負 N 倍。負號就是冷次定律：感應效果會反抗原本的磁通量變化。

ℰ＝−NdΦBdt

如果磁通量作正弦變化：

ΦB(t)＝Φmax sin(ωt)
ℰ(t)＝−NωΦmax cos(ωt)
ℰ(t)＝ℰmax sin(ωt − π2)

所以磁通量最大時，斜率為 0，感應電壓反而是 0；磁通量通過 0 時，斜率最大，感應電壓的大小反而最大。

④ 90° 相位差不是傳播延遲

正弦函數微分後會變成餘弦函數，因此兩條波形在橫軸上錯開四分之一週期。這只是函數關係造成的相位差。

T＝2πω ； Δφ＝π2
Δtgraph＝Δφω＝T4

以臺灣市電 60 Hz 為例：

T＝160 Hz＝16.7 ms
Δtgraph＝16.7 ms4＝4.17 ms
4.17 ms 是圖上的相位間距，不是電磁訊號花了 4.17 ms 才傳過去。

⑤ 感應電壓與感應電流要分開

法拉第定律先決定感應電壓；有沒有電流、電流多大、電流是否再落後，還要看二次側是否形成閉合迴路，以及負載的阻抗。

Ĩs＝ṼsZload
ZRL＝R ＋ jωL ； φ＝tan−1(ωLR)
  • 開路：有感應電壓，但二次電流近似為 0。
  • 純電阻負載：電流與二次電壓近似同相。
  • 含電感負載：電流還會再落後電壓一個角度 φ。

本頁動畫為了看見二次電流，假設二次側已接上近似電阻負載。

⑥ 變壓器公式與計算例

理想變壓器的兩組線圈穿過近似相同的磁通量，因此每一匝的感應電壓相同，總電壓與匝數成正比。

VsVp≈NsNp ； VpIp≈VsIs

例：一次側 500 匝接 110 V，二次側 100 匝。若二次側接 11 Ω 純電阻負載：

Vs＝110 V × 100500＝22 V
Is＝22 V11 Ω＝2.0 A

這是理想值；真實變壓器還會有線圈電阻、漏磁、渦電流與磁滯損失。

一句話判讀： 先看磁通量，再看它的斜率；斜率決定感應電壓，負載再決定感應電流。動畫中的四分之一週期是相位關係，不是電磁場慢慢傳過去。
🎓 資優／高中補充

感應電流為什麼有時和一次電流同方向？

先講結論：冷次定律是「反抗磁通量的變化」，不是「永遠和原電流反向」。磁通量變強時，感應磁場反抗它，方向相反；磁通量變弱時，感應磁場要把它補回來，方向相同。交流電是正弦函數，磁場一個週期內會變強、變弱各兩次，所以二次電流與一次電流的方向關係，每四分之一週期就換一次。

① 先約定符號與簡化模型

設兩個線圈繞向相同，鐵芯中沿逆時針方向的磁通量為正。沿用本頁動畫的簡化：鐵芯磁通量與一次電流同相，二次側接純電阻負載，所以二次電流與感應電壓同相。

Φ＝Φmax sin ωt ； Ip ∝ sin ωt
εs＝−Ns dΦ/dt＝−NsωΦmax cos ωt ； Is ∝ −cos ωt

② 四個四分之一週期逐段看

  • 0 ～ T/4：Φ 為正且變強 → 感應磁場反抗 → Is 與 Ip 方向相反。
  • T/4 ～ T/2：Φ 為正但變弱 → 感應磁場補回 → Is 與 Ip 方向相同。
  • T/2 ～ 3T/4：Φ 為負且變強（磁場反向後增強）→ 感應磁場反抗 → 方向相反。
  • 3T/4 ～ T：Φ 為負但變弱 → 感應磁場補回 → 方向相同。

判斷訣竅：看磁場「變強或變弱」，不要看它的正負。變強 → 感應電流反向；變弱 → 感應電流同向。

③ 用乘積一眼看出來

Ip Is ∝ −sin ωt cos ωt＝−½ sin 2ωt
乘積為正 → 同方向；乘積為負 → 反方向。

這個乘積以兩倍頻率正負交替，同向與反向各占一半時間，平均為零。所以二次電流對一次電流沒有固定的「同向」或「反向」；有時同向，是正弦交流電的正常現象，不是動畫畫錯。

④ 真實變壓器要再多想一步

真實變壓器的一次電流由兩部分組成：產生鐵芯磁通量的磁化電流，以及用來抵銷二次電流磁通的負載電流。因此接上負載後，鐵芯磁通量大致仍由一次電壓決定。本頁為了看清楚感應方向，只用「一次電流與磁場同相」的簡化模型。

一句話判讀： 冷次定律是「反抗變化」：磁場變強時感應電流反向，變弱時同向；正弦交流電每四分之一週期就換一次，所以二次電流有時與一次電流同方向。

電磁爐明明表面沒有火，摸起來也不燙，為什麼放上金屬鍋子卻能把水煮沸？

底下磁場改變，上面就感應出電流

電磁爐底下的線圈通交流電，磁場方向每半週期反轉。金屬鍋底因磁通量改變而產生環狀感應電流，稱為渦電流。

  • 慢動作固定為每秒一個週期。
  • 鍋底渦電流方向依冷次定律反抗磁場改變。
  • 金屬電阻讓電能轉換成熱。
電能 → 改變的磁場 → 渦電流 → 熱
