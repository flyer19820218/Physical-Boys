- 細線懸吊的磁鐵靜止後，指向北方的那一端稱為什麼？
- 懸吊磁鐵受地磁影響，指向北方的一端稱為指北極（N 極），指向南方的稱為指南極（S 極）。
- 指北，就叫 N 極。
- 兩塊磁鐵的 N 極與 N 極靠近時，會發生什麼事？
- 同名極相斥、異名極相吸，所以 N 與 N 互相排斥。
- 同名還是異名？
- 將一塊磁鐵等分成三段，總共會出現幾個 N 極與幾個 S 極？
- 每一段切斷後都會成為具備完整雙極的新磁鐵，所以共 3 個 N 極與 3 個 S 極。
- 切斷時磁極會不會消失？每一段是不是都是獨立的磁鐵？
- 下列哪一組都是磁性物質？
- 能被磁鐵吸引並被磁化的磁性物質有鐵、鈷、鎳及其合金。
- 三種金屬的名字都是「金」字旁。
- 高溫加熱或劇烈撞擊磁鐵，為什麼會使它失去磁性？
- 磁疇排列整齊時整體有磁性；加熱或撞擊使磁疇回到凌亂，磁性就消失。
- 小磁區的排列變得凌亂。
- 工廠要製造能長時間吸在冰箱上的造型磁鐵，內部應該選軟鐵還是鋼？
- 軟鐵，磁性長久保存
- 鋼，磁性很容易消失
- 軟鐵，不可能被磁化
- 鋼，磁性可長久保存
- 鋼是硬磁性物質，不易磁化但磁化後磁性可長久保存，適合做永久磁鐵；軟鐵磁性容易消失。
- 軟鐵的磁性容易消失，鋼的可以長久保存。
- 磁鐵外部的磁力線方向如何？
- 磁鐵外部的磁力線由 N 極出發，回到 S 極，形成封閉曲線。
- 外部由 N 出發。
- 磁力線較密集的地方，代表磁場怎樣？
- 磁力線的疏密代表磁場強弱，越密集磁場越強。
- 疏密程度就是強弱。
- 長條形磁鐵正中央的磁力線非常稀疏，代表什麼？
- 稀疏表示磁場微弱（中性區），磁力主要集中在兩端磁極。
- 磁力線的「疏密程度」代表磁場的什麼特性？
- 空間中某點的磁場方向是怎麼定義的？
- 將指南針放在磁場中，其 N 極所指的方向就是該點的磁場方向。
- 用指南針來定義。
- 磁場方向與該點磁力線的關係是什麼？
- 磁場方向與該點磁力線的切線方向一致，小磁針會順著切線轉動。
- 切線方向就是瞬間飛出去的方向。
- 小磁針放在磁鐵外部正中央的上方，磁針的 N 極會指向哪個方向？
- 平行磁鐵，朝向 N 極
- 平行磁鐵，朝向 S 極
- 垂直向上，遠離磁鐵
- 垂直向下，朝向磁鐵
- 該處磁力線從 N 極走向 S 極，切線方向平行磁鐵並朝向 S 極，所以磁針 N 極指向 S 極那端。
- 磁力線是從 N 極出發走向 S 極。
- 為什麼指南針的 N 極會指向地理北方？
- 地球本身是一顆巨大的磁鐵，周圍有地磁場，指南針的 N 極被地磁場拉向北方。
- 地球周圍有地磁場。
- 地理北極附近的地磁極實際上是什麼極？
- 指南針 N 極被吸向北方，由異名相吸可知北方附近是 S 極；地理北極附近是地磁 S 極。
- 異名極才會相吸。
- 地球外部的磁力線方向如何？
- 地磁 N 極在地理南極附近，磁力線由南半球出發，流向北半球的地磁 S 極，所以是從南流向北。
- 磁力線永遠從 N 極出發。
