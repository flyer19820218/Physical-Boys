- 奧斯特在 1820 年發現了什麼現象？
- 導線通電時旁邊的指南針發生偏轉，證明電流會產生磁場（電流的磁效應）。
- 電流周圍藏著磁場。
- 長直導線通電後，周圍的磁力線是什麼形狀？
- 長直導線的磁力線是以導線為圓心的同心圓，方向與電流垂直，越靠近導線磁場越強。
- 磁場與電流方向互相垂直。
- 鉛直導線電流由下向上，導線「東方」的小磁針 N 極會指向哪裡？
- 右手大拇指朝上，四指逆時針彎曲；在導線東側，磁場的切線方向朝北，所以磁針 N 極指向北方。
- 用右手大拇指朝上，四指會呈現逆時針旋轉。
- 長直導線彎成圓形線圈後，線圈中心的磁場有什麼變化？
- 線圈中心區域所有圓段產生的磁場方向一致，互相疊加，產生極強的磁場。
- 中心區域磁場方向一致。

- 大拇指代表 N 極。
- 圓形線圈電流為「順時針」時，線圈正面（靠近我們的一面）是什麼磁極？

- 大拇指是指向自己，還是穿入紙面？
- 螺線管可以看成什麼東西疊合在一起？
- 螺線管是許多圓形線圈疊合，通電後各線圈的磁場互相疊加、增強。
- 把線圈一圈圈疊起來。
- 螺線管表面電流向下，四指向下彎曲，大拇指朝左，哪一端是 N 極？
- 大拇指所指的方向就是 N 極，所以左端是 N 極。
- 螺線管通電後，把電流方向反轉，周圍的小磁針會怎樣？
- 電流反向，大拇指（N 極）方向也反向，N、S 極互換，所以小磁針全部反轉 180 度。
- 電流方向改變，大拇指的方向會不會跟著改變？
- 電磁鐵是在螺線管內插入什麼製成的？
- 在螺線管內插入軟鐵芯，通電時軟鐵被磁化，與線圈磁場疊加，磁力大增。
- 要容易被磁化的材料。
- 下列哪一種做法無法增強電磁鐵的磁力？
- 增加匝數、增加電流、插入鐵芯都能增強磁力；減少匝數反而讓磁力變弱。
- 三大要素：匝數、電流、鐵芯。
- 起重機的軟鐵芯換成鋼，會引發什麼問題？
- 鋼是硬磁性物質，被磁化後斷電仍保有磁性，汽車掉不下來，失去隨意控制吸放的功能。
- 鋼磁化後，斷電磁性會不會消失？
- 電話的話筒（麥克風）把聲音轉換成什麼？
- 聲波震動使碳粉忽鬆忽緊，電阻改變，於是聲波變成大小改變的電流。
- 聲音震動讓電阻改變。
- 聽筒內的電磁鐵磁力為何忽強忽弱？
- 話筒送來的電流大小不斷變化，電磁鐵的磁力也跟著忽強忽弱，帶動金屬片震動發聲。
- 磁力跟電流大小有關。
- 電話通話中，能量依序是怎麼轉換的？
- 話筒把聲能變成電能，電流在聽筒電磁鐵產生磁能，再推動振膜還原成聲能。
- 先收音，再傳送，最後發聲。
