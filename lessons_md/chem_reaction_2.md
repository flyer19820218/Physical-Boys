## 分頁：係數還是下標？（反應式書寫原則） `[reaction-rules]`

> 曉臻老師開場
> 打火機一按，丁烷就燒起來了。化學家把這件事寫成一行反應式，全世界的人都看得懂。可是要小心：H₂O 前面的大 2 和右下角的小 2，只差一個位置，意思完全不一樣——改錯了，水就變成雙氧水！ 先讀書寫原則，再到實驗台上，把係數和下標都按按看。

#### 化學反應式的基本原則
將微觀的物質變化轉譯為標準科學符號：
- 反應物與生成物：反應物在左，生成物在右，多種物質以「+」連接。
- 反應方向：以化學反應箭頭表示進行方向。
- 狀態標示：利用 _((s))固態、_((l))液態、_((g))氣態、_((aq))水溶液 標明物理狀態。氣體逸散用「↑」，沉澱用「↓」。
- 反應條件：溫度、壓力或催化劑需標示於箭頭上方。加熱統一標示為「△」。

## 分頁：左右原子要對帳（觀察法係數平衡） `[observation-method]`

#### 解題核心原則
根據質量守恆定律，原子種類與數目前後必須完全相等。觀察法步驟：
- 尋找原子數最多的複雜分子，將其係數設為 1。
- 依序平衡金屬與非金屬原子。
- 將純元素物質（如 O₂ 或 H₂）留至最後進行平衡。
- ［按鈕］氫氣燃燒反應
- ［按鈕］丙烷燃燒反應

#### 互動逐步推導區
反應式： Mg + O₂ → MgO
初始狀態： 左方含有 1 個 Mg、2 個 O；右方含有 1 個 Mg、1 個 O。
第一步： 平衡氧原子，於右方 MgO 補上係數 2。 Mg + O₂ → 2 MgO
第二步： 為平衡鎂原子，於左方 Mg 補上係數 2。 完成式： 2 Mg + 1 O₂ → 2 MgO
反應式： H₂ + O₂ → H₂O
初始狀態： 鎖定原子數最多的水分子 H₂O 為基準。
第一步： 兩側氧原子不平衡（左 2 右 1），於 H₂O 前補上係數 2。 H₂ + O₂ → 2 H₂O
第二步： 右方現有 4 個氫，因此左方 H₂ 需補上係數 2。 完成式： 2 H₂ + 1 O₂ → 2 H₂O
反應式： C₃H₈ + O₂ → CO₂ + H₂O
初始狀態： 以最複雜的 C₃H₈ 為基準（係數設為 1）。
第一步： 平衡碳與氫，分別於 CO₂ 前填入 3，H₂O 前填入 4。 C₃H₈ + O₂ → 3 CO₂ + 4 H₂O
第二步： 計算右側氧原子共 10 個，左側 O₂ 填入 5。 完成式： 1 C₃H₈ + 5 O₂ → 3 CO₂ + 4 H₂O

## 分頁：猜不到就設未知數（代數法係數平衡） `[algebraic-method]`

> 曉臻老師的挑戰
> 乙烷燃燒，氧氣前面到底要填幾？用猜的：3 不對、4 也不對，一路猜下去沒完沒了。遇到這種題目，就把每個係數都當成未知數 a、b、c、d——每一種原子列一條等式，讓數學把答案算出來。 最下面的工作台會把你填的係數即時代進每一條等式，一眼看出哪一條還不成立。

#### 代數法核心原則
面對結構複雜的反應式，採用代數未知數聯立求解以確保精確：
- 設定未知數：a, b, c, d... 依序標示於分子前。
- 依據各元素之原子數守恆，列出聯立方程式。
- 令最複雜之分子係數為 1，求解後將全體化為最簡整數比。
- ［按鈕］氨氣生成反應
- ［按鈕］乙烷燃燒反應
- ［按鈕］鋁與鹽酸反應

#### 代數法逐步推導區
反應式： a N₂ + b H₂ → c NH₃
初始狀態： 列出 N 與 H 的原子守恆等式： N 原子：2a = c H 原子：2b = 3c
第一步： 令最複雜的 NH₃ 係數 c = 1，代入 N 守恆 2a = 1，得出 a = 12。
第二步： 將 c = 1 代入 H 守恆方程式 2b = 3(1)，得出 b = 32。為求最簡整數比，全體數值同乘 2。 完成式： 1 N₂ + 3 H₂ → 2 NH₃
反應式： a C₂H₆ + b O₂ → c CO₂ + d H₂O
初始狀態： 列出原子守恆等式： C：2a = c H：6a = 2d O：2b = 2c + d
第一步： 令最複雜的 a = 1，解得 c = 2、d = 3。
第二步： 代入氧原子等式解得 b = 72，為求最簡整數比，全體數值同乘 2。 完成式： 2 C₂H₆ + 7 O₂ → 4 CO₂ + 6 H₂O
反應式： a Al + b HCl → c AlCl₃ + d H₂
初始狀態： 列出原子守恆等式： Al：a = c H：b = 2d Cl：b = 3c
第一步： 令最複雜之 c = 1，可得 a = 1、b = 3。
第二步： 數值代入 H 守恆得 3 = 2d，故 d = 32。全體數值同乘 2。 完成式： 2 Al + 6 HCl → 2 AlCl₃ + 3 H₂

## 分頁：係數比不是重量比（反應式微觀意義） `[micro-meaning]`

> 曉臻老師的疑問
> 2 H₂ + O₂ → 2 H₂O，係數是 2 : 1 : 2。那是不是 2 公克氫氣配 1 公克氧氣？ 不是！係數數的是分子的「個數」，不是重量。一個氧分子比一個氫分子重 16 倍。在下面切換「數個數」和「秤重量」比比看。

#### 平衡係數的科學涵義
以水分子生成 2 H₂ + O₂ → 2 H₂O 為例，其平衡係數比 2 : 1 : 2 具備以下意義：
- 分子數比例：2 個氫分子與 1 個氧分子發生反應。
- 莫耳數比例：2 莫耳與 1 莫耳。
- 氣體體積比例（同溫同壓條件）：2 公升與 1 公升。

先選放大倍數，再切換「數個數」和「秤重量」，看比例有沒有跟著變。

#### 核心易錯觀念澄清
⚠️ 重點提醒：係數比不等於質量比
計算質量時，必須經過「莫耳數 × 分子量」的換算程序。上述反應之精確質量比為：

## 分頁：電子的得失帳本（氧化還原法推導） `[redox-method]`

> 曉臻老師的進階挑戰
> 銅片放進稀硝酸，會冒出氣泡、溶液慢慢變藍。這種反應原子一大堆，用觀察法數到眼花。其實訣竅只有一個：銅丟掉的電子，一定全部被氮接走。 讓失去的電子和得到的電子一樣多，係數就出來了。這是高中先修內容，挑戰看看！

#### 高階解析：氧化還原與氧化數
- ［按鈕］氧化數定義與規則
- ［按鈕］過錳酸鉀滴定 (進階)
氧化數（Oxidation Number）： 為追蹤化學反應中「電子轉移」過程所建立之計量工具。氧化數增加（失去電子）為氧化反應；氧化數減少（獲得電子）為還原反應。
實用指定守則：
- 單一元素或自由狀態，氧化數為 0。
- 氫原子於化合物中通常為 +1。
- 氧原子於化合物中通常為 -2。
- 中性化合物內，全體原子之氧化數總和必等於 0。
反應式： C + H₂SO₄ → CO₂ + SO₂ + H₂O
初始狀態： 尋找發生氧化數改變的核心原子。
第一步（尋找電子轉移）：
- C 氧化數從 0 變成 +4（失去 4 個電子）。
- S 氧化數從 +6 變成 +4（得到 2 個電子）。
第二步（最小公倍數平衡）： 失去 4 個電子與得到 2 個電子，最小公倍數為 4。碳不變（係數 1），硫必須乘以 2 才能滿足電荷守恆。 C + 2 H₂SO₄ → CO₂ + 2 SO₂ + H₂O
第三步（平衡氫與氧）： 左側有 4 個 H，因此右側 H₂O 需補上 2。檢查氧原子，左右兩側皆為 8，平衡完成。 完成式： 1 C + 2 H₂SO₄ → 1 CO₂ + 2 SO₂ + 2 H₂O
反應式： Cu + HNO₃ → Cu(NO₃)₂ + NO + H₂O
初始狀態： 若使用代數法將產生多個未知數。改用氧化還原法精確處理。
第一步（尋找電子轉移）：
- Cu 氧化數從 0 變成 +2（失去 2 個電子）。
- 部分 HNO₃ 中的 N 氧化數從 +5 變成 +2（得到 3 個電子）。
第二步（得失電子平衡）： 為了遵守電荷守恆，氧化失去的電子總數必須等於還原得到的電子總數。我們必須找出得失電子數的最小公倍數。 2 與 3 的最小公倍數為 6。因此 Cu 係數乘以 3，生成物 NO 係數乘以 2。 3 Cu + HNO₃ → 3 Cu(NO₃)₂ + 2 NO + H₂O
第三步（平衡剩餘原子）： 右側共有 8 個 N（3×2 + 2），故左側硝酸補上 8。左側有 8 個 H，右側水補上 4。 完成式： 3 Cu + 8 HNO₃ → 3 Cu(NO₃)₂ + 2 NO + 4 H₂O
⚠️ 挑戰級關卡：本題難度極高（進階），請深呼吸後再進行推導！
反應式： MnO₄⁻ + C₂O₄²⁻ + H⁺ → Mn²⁺ + CO₂ + H₂O
初始狀態： 這是高中最經典的滴定反應，觀察法難以配平電荷，請先標示出發生氧化數改變的核心原子。
第一步（尋找電子轉移）：
- Mn 氧化數從 +7 變成 +2（得到 5 個電子）。
- C 氧化數從 +3 變成 +4，但每個草酸根含 2 個碳，故共（失去 2 個電子）。
第二步（最小公倍數平衡）： 失去 2 個與得到 5 個，最小公倍數為 10。因此過錳酸根需乘以 2，草酸根需乘以 5（右側生成物同步乘上倍數）。 2 MnO₄⁻ + 5 C₂O₄²⁻ + H⁺ → 2 Mn²⁺ + 10 CO₂ + H₂O
第三步（平衡電荷與氫氧）： 左側電荷為 -12，右側為 +4，故左側需補上 16 個 H⁺。16 個氫則對應右側 8 個水分子。 完成式： 2 MnO₄⁻ + 5 C₂O₄²⁻ + 16 H⁺ → 2 Mn²⁺ + 10 CO₂ + 8 H₂O
