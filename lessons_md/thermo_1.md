- 科學原理｜液體熱脹冷縮，細管把微小體積變化放大
- 溫度計與環境接近熱平衡後，液體溫度改變。受熱時粒子運動加快、平均距離略增，液體體積增大；多出的液體進入細管，因此液柱上升。冷卻時相反。
- 同樣的體積變化，細管越窄，液柱升得越明顯
- 拖動溫度，再切換粗管與細管。找出哪種管徑能把同樣的膨脹看得更清楚。
- 玻璃管旁只有一把 0～10 cm 的直尺，卻沒有溫度刻度。只要知道液柱長度，你能反推出現在幾度嗎？
- 科學原理｜先量長度，再用兩個固定點把 cm 翻譯成 °C
- 在標準大氣壓下，把冰水的液面位置定為 0 cm／0°C，把沸水的液面位置定為 10 cm／100°C。兩者之間是線性等分，因此左邊的長度尺可以轉換成右邊的攝氏溫標。
- 0～10 cm 對應 0～100°C，所以每 1 cm 對應 10°C

- 攝氏把水的冰點與沸點標成 0 與 100；華氏標成 32 與 212。兩段刻度都是等距的，因此可以用等比例關係互相翻譯。

- 資優原理｜凱氏溫標從理論上的最低溫開始計數
- 0 K 等於 −273.15°C，稱為絕對零度。這是物質熱運動能量所能到達的理論最低狀態；真實微觀世界仍須用量子理論描述，不能簡化成「所有粒子完全不動」。
- K = °C + 273.15，而且凱氏溫度不低於 0 K

- 粒子模型為教學示意，非真實比例
- 🔬 溫度計不是「熱往上跑」液體受熱後體積略增。玻璃容器把液體限制在球部與細管中，多出的體積只能沿細管上升；冷卻時液體收縮，液柱下降。細管截面積越小，同樣體積變化造成的高度變化越大。 **真正測量要等讀值穩定：**只有當溫度計與被測物接近熱平衡，液柱讀值才可代表被測物溫度。

- 🧪 長度本身就是一把尺這裡把 **0°C 的液面位置設為長度 0 cm**，把 **100°C 的液面位置設為 10 cm**。左邊永遠保留 0～10 cm 的長度尺；右邊是校準後得到的 0～100°C 溫度尺。於是每增加 1 cm，就代表增加 10°C。 T − 0100 − 0 = L − 010 − 0 神秘飲料讓液柱從 0°C 基準線上升 3.7 cm，因此 **T = 37°C**。這個 0 cm 是我們選定的測量起點，不是從玻璃球最底端量起。
